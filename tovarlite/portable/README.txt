TovarLite portable
------------------
Double-click TovarLite.vbs (or TovarLite.lnk after the first run).

On launch you choose:
  Jagex Account     — sign in with the Jagex Launcher on this PC
  Email & password  — sign in on the Old School title screen

Each start refreshes the official RuneLite launcher, which then downloads
the current game client. You do not need to rebuild this zip after a game
update.

Login details are never stored in this zip. Each computer signs in itself.

Java is included in App\jre. You do not need to install Adoptium.

To re-copy plugins and settings from this zip into %USERPROFILE%\.runelite,
run App\Re-import-settings.bat, then launch again.
