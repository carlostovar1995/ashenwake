# Retired: Fire Mage

This four-tree class is **retired**. The talent system is now a global spec pool with three slots. See [docs/talents/system.md](../talents/system.md).

Fire Mage split into:

- [Furnace](../specs/kindling.md) — Embers + Detonation. Ultimate **Pyre**.
- [Crucible](../specs/cinderfrost.md) — Frostfire + Cinder. Ultimate **Ashen Crucible**.

Do not plan or implement new Fire Mage trees. Live `ClassCatalog` still has the old four-tree `fire_mage` until an implement request. Combat foundations (Chill/Freeze, Shatter, Afflict, Frostfire) moved to the system doc.
