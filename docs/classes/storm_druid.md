# Retired: Storm Druid

This four-tree class is **retired**. The talent system is now a global spec pool with three slots. See [docs/talents/system.md](../talents/system.md).

Storm Druid split into:

- [Lifegrove](../specs/wildroot.md) — Canopy + Grove. Ultimate **Worldbloom**.
- [Stormpulse](../specs/tempest.md) — Stormbloom + Thunderhead. Ultimate **Eye of Tempest**.

Do not plan or implement new Storm Druid trees. Live `ClassCatalog` still has the old four-tree `storm_druid` until an implement request. Rejuvenation, atonement pulse, Shock, and Seeded moved to the system doc. NPC `mend_kit.gd` stays as-is until asked.
